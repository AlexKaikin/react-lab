# Ревьюер

Контекст проекта: изучить структуру, правила, зависимости — AGENTS.md, package.json, README.md.

## Чек-лист для ревью кода

### 1. Конвенции проекта

- Соблюдать структуру FSD и гайдлайн именований (см. AGENTS.md)
- Запрет кириллицы в именах файлов/путей
- Единый стиль экспорта, без двойного реэкспорта в barrel

### 2. Архитектура FSD & Импорты

- Направление зависимостей: shared → entities → features → widgets → pages → app
- Запрет кросс-доменных импортов внутренних файлов (только через index.ts слайса)
- Нет циклических зависимостей
- Чистые barrel-файлы (ISP) — index.ts экспортирует только публичное API слайса

### 3. Tailwind CSS & Вёрстка

- Запрет arbitrary values (`w-[50%]`) без веской причины
- Валидные единицы измерения
- Стандартные значения шкалы (`gap-24`, не `gap-25`)
- Нет дублей, мёртвых классов, `!important`

### 4. TypeScript & Типизация

- Запрет `any`/`unknown` без type guards
- Компоненты типизируются как `FC<Props>` / `React.FC<Props>`, `className` указывается прямо в Props (см. button.tsx, modal.tsx)
- Интерфейсы соответствуют реальному использованию (ISP)
- Нет неиспользуемых полей

### 5. React & Производительность

- `'use client'` при хуках и браузерных API
- Корректные массивы зависимостей в useCallback/useMemo
- React.memo — только при измеримой пользе
- next/dynamic / React.lazy для тяжёлых компонентов и модалок (см. AGENTS.md, «Ленивая загрузка модалок»)
- `getTranslations` в Server Components — только с явным `{ locale, namespace }`, никогда голый `getTranslations(namespace)` (тихо ломает статику, см. AGENTS.md)
- Функции работы с локализованными данными (репозитории) принимают `locale` явным параметром, отдают fallback только для дефолтной локали, для остальных — `null`/404 при отсутствии перевода (см. AGENTS.md, «Локализация данных»)

### 6. SOLID & Чистый код

- SRP: длинные файлы — сигнал для декомпозиции
- DRY: выносить дубли в утилиты/компоненты
- OCP: конфигурация вместо if/else цепочек
- DIP: зависимости от интерфейсов, не реализаций

### 7. Доступность (a11y)

- ARIA-атрибуты для интерактивных элементов без текста (кнопка только с иконкой — обязателен aria-label)
- Keyboard navigation (Tab, Enter, Escape)
- Контрастность WCAG AA
- Семантика (`button` вместо `div onClick`)
- Локализация a11y-строк (aria-label, alt, title, placeholder) через next-intl

### 8. SEO

- У каждой страницы `generateMetadata` возвращает `alternates.canonical` и `alternates.languages` через `buildMetadata` (не голый `return { title, description }`)
- Тонкий/дублирующийся контент (авто-сгенерированные листинги вроде тег-страниц) — `noindex`, а не просто исключение из sitemap (иначе поисковик всё равно найдёт по внутренним ссылкам)
- `sitemap.ts` строится из реальных данных (какие переводы/страницы действительно существуют), а не декартова произведения локалей и сущностей — иначе hreflang/URL ведут на 404
- Структурированные данные (JSON-LD) для контентных страниц, где это применимо (`Article`, `BreadcrumbList`)
- Ровно один `h1` на странице

### 9. Безопасность & Надёжность

- Валидация входных данных и API через Zod — пункт неактуален, пока Zod не установлен; включить в чек-лист, когда появится в проекте
- Early return для пустых данных
- Экранирование пользовательского контента (XSS)
- Error Boundaries с fallback-UI

### 10. Code Style & Гигиена

- Сортировка импортов (внешние → внутренние → типы)
- Чистое форматирование, нет пустых контейнеров
- Нет опечаток в именах и текстах
- Комментарии только для нетривиальной логики
